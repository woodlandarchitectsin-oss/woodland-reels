# Project inbox (Friday Reels)

Drop a folder per project you want featured: `projects/<project-name>/` with
- `plan.png` (or .jpg/.pdf export): the floor plan, white background works best
- `render1.jpg`, `render2.jpg` … and/or `site1.jpg` … (3–5 images)
- `info.txt`: name, location, plot size, built-up area, 3 highlights (e.g. "east-facing courtyard", "double-height living")

Or just send the files to Claude in the Friday chat when it asks. Used folders get `used: <date>` added to info.txt.
